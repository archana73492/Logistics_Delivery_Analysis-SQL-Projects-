


# 🚚 Logistics & Delivery Analytics (SQL Project)

## 📌 Problem Statement
Analyze logistics data to identify delivery delays, top agents, and customer behavior.

## 🧰 Tools Used
- SQL (MySQL/PostgreSQL)
- Excel (for dataset)

## 📊 Steps Performed
1. Created database schema
2. Inserted sample data
3. Performed SQL queries for analysis
4. Generated business insights

## 🔍 Key Insights
- Delayed deliveries impact customer satisfaction
- Few agents handle most deliveries
- High-value customers contribute major revenue
- Delivery time varies by city

## 📈 Sample Queries
- Delayed orders
- Revenue analysis
- Customer segmentation
- Delivery performance
